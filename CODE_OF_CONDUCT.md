# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone taking part in issues, pull requests and discussions is expected
to follow it.

## Reporting

Report unacceptable behavior to the maintainer, [@CarlosLeonCode](https://github.com/CarlosLeonCode),
through the contact details on that GitHub profile. If you have no private channel, or the report
involves the maintainer, use [GitHub's report abuse form](https://github.com/contact/report-abuse).
Reports are handled confidentially.
